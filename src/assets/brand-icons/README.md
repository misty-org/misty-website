Official brand artwork for the homepage sync animation, copied from the Misty app's shared brand icons (`misty/src/shared/ui/icons/brand-icons`). `sources.json` records where each file came from. GitHub and Linear are single-color marks, so they use the white silhouette the app paints on dark surfaces; the homepage is always dark. Every other logo keeps its original colors. Trademarks remain the property of their owners.

To update a logo, copy the new file from the app's brand icons rather than drawing or recoloring one here.
