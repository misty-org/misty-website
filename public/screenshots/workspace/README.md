# Example space captures

Add these six PNGs and refresh the page. No code changes needed. Prefer 1600 × 1000 screenshots without browser chrome or personal information.

- `product-launch.png` — Milestones, decisions, and release materials in a shared launch space.
- `research-project.png` — Sources, observations, and findings gathered in a research space.
- `shared-household.png` — Household plans, responsibilities, and useful information together.
- `creative-project.png` — References, drafts, and feedback for a creative project.
- `study-space.png` — Coursework, practice, and progress organized for studying.
- `community-event.png` — Activities, logistics, and participants for a community event.
